# Дизайн-система и UI-паттерны

> Правила визуального оформления и взаимодействия. Не нарушать без обсуждения.

## Общие принципы

**Notion/Obsidian aesthetic**: минимализм, тёмная тема, чёткая иерархия, без украшений. Никаких градиентов, теней, скруглений больше 8px.

**Цвета**: только CSS-переменные. Основные: `var(--text-primary)`, `var(--text-dim)`, `var(--text-muted)`, `var(--border)`, `var(--bg-hover)`, `var(--bg-active)`.

**Иконки**: только `@ant-design/icons`. Без эмодзи. Иконки-онли кнопки всегда с `<Tooltip>`.

**Адаптивность**: каждый компонент должен работать на `< 768px`. Брейкпоинт в CSS Modules: `@media (max-width: 767px)`.

**Шрифты**: 14px body, 12px secondary, 10px labels, 16px page titles. Font-weight: 400 normal, 500 medium, 600 headings.

### Активная страница

Все навигационные элементы подсвечивают активную страницу:
- `usePathname()` + `startsWith(route)`
- Стиль: `background: var(--bg-active); color: var(--text-primary);`

### Кнопка режима

- Обычный `<button>`, НЕ Ant Design Button
- Стиль: наследует от кнопок импорта/экспорта, но с левым акцентом `border-left: 3px solid var(--text-dim)`
- На всю ширину
- Никакого `danger` или цветного фона — нейтральный

## Шапки страниц

### Единый компонент `PageHeader`

**Все страницы** используют `<PageHeader title="..." actions={...} />` из `src/shared/ui/page-header.tsx`. Никаких inline-стилей, отдельных `<h2>`, самописных header-дивов.

```
┌──────────────────────────────────────────┐
│ ☰  Page Title              [действия]    │
└──────────────────────────────────────────┘
```

- В мобилке: кнопка `MenuOutlined` слева от заголовка (на одной строке, не отдельным рядом)
- Заголовок: 14px, font-weight 600, без иконок в заголовке
- Действия: `margin-left: auto`
- Разделитель снизу: `border-bottom: 1px solid var(--border)`
- Ширина: `max-width: var(--content-width); margin: 0 auto`
- Мобилка: `padding: 6px 12px; font-size: 13px`
- Кнопка меню через `MobileMenuProvider` (React Context) — Shell оборачивает children

### Страницы с ChatPanel

ChatPanel рендерит свою шапку с мобильной кнопкой меню через `useMobileMenu()`. Шапка показывается даже без заголовка на мобилке (только кнопка меню).

## Формы и страницы настроек

### Страница настроек (AI, профиль)

- Ширина: `440px`, `max-width: 100%` — на мобилке растягивается на весь экран
- Центрирована `margin: 0 auto`
- Поля — простые `<div>` с label сверху, без Ant Design `Card`
- Label: `font-size: 12px; color: var(--text-muted); marginBottom: 4px`
- Отступ между полями: `gap: 14px`
- Кнопка сохранения внизу, на всю ширину
- Шапка: через `PageHeader` компонент

### Select (выпадающие списки)

- Стандартный Ant Design `Select` с `width: "100%"`
- Для больших списков (модели AI): `listHeight={256}` — Ant Design сам виртуализирует
- Не использовать `react-window` — несовместим с текущей версией
- При загрузке опций: `notFoundContent={<Spin size="small" />}`

## Таблицы

### Стиль

- `size="small"`
- `pagination={{ pageSize: 20, hideOnSinglePage: true }}`
- Вся строка кликабельна: `onRow` с `cursor: pointer`

- Таблица → клик по строке → `<Modal>` с контентом
- Контент: Markdown через `MdViewer` (react-markdown), либо `white-space: pre-wrap` для plain text

## Чат

### Шапка

```
│ ☰  Настройка AI мастера      🗑  📋 │
```

- Мобильная кнопка меню слева (через `useMobileMenu()`)
- Заголовок: `font-size: 13px; font-weight: 600`
- Кнопки действий справа: `type="text" size="small"`
- Ширина шапки: `max-width: var(--content-width); margin: 0 auto`
- Разделитель снизу: `border-bottom: 1px solid var(--border)`
- На мобилке без заголовка — только кнопка меню (пустая шапка)

### Сообщения

- Админ: справа, фон `var(--bg-hover)`, border-radius: 12px (правый нижний 4px)
- Мастер/Builder: слева, фон `var(--bg-bubble)`, border: 1px solid var(--border)
- Аватары: 32px, иконка зависит от роли (UserOutlined, RobotOutlined, CodeOutlined)
- Текст: `white-space: pre-wrap; word-break: break-word`
- Кнопки действий (copy/delete) на бабле, opacity 0 → 1 при hover строки

### Поле ввода

- `Input.TextArea` + кнопка Send рядом
- Контролируемое состояние (`value + onChange`), НЕ ref (Ant Design TextArea ref не работает)
- Enter = отправить, Shift+Enter = новая строка
- Блокируется при отправке (`disabled={sending}`)

### Индикатор набора (typing)

- Три анимированные точки в бабле мастера
- CSS анимация `dotPulse`: opacity + scale, задержка 0.2s между точками

### Переключатель режимов (Мозг/Память) на мобилке

- В десктопе: рядом с полем ввода (в `inputInner` flex-ряду)
- На мобилке: `flex-wrap: wrap` + `width: 100%` → на отдельной строке над инпутом

### Прогресс-бар файлов

- Компактная строка над инпутом: `📁 2/3 │ 📄 15/32 [⚙] [▶]`
- Все элементы по правому краю (`justify-content: flex-end`)
- `⚙` (SettingOutlined) → tooltip «Детали файлов» → модалка с per-file breakdown
- `▶` (CaretRightOutlined) → tooltip «Продолжить изучать» → продолжение обработки
- При активной обработке: `▶` → `■` (StopOutlined), удаление файлов заблокировано
- Все файлы обработаны → кнопка продолжения скрыта
- Модалка: per-file прогресс-бары, статусы (Готово/Читается/Ожидает), удаление
- Ширина прогресс-бара: `max-width: var(--content-width)`

### История чата

- Кнопка `HistoryOutlined` в шапке
- Модалка с `<Table>` — два столбца: роль + сообщение
- В столбце сообщения: прикреплённые файлы (📎 + имена) над текстом — как в чате
- Пагинация 30 записей на страницу
- Без поля ввода — только чтение

## Модалки (Modal)

- `centered` — всегда по центру экрана
- Ширина: зависит от контента (300-640px)
- Footer: кнопки Cancel (слева) + Primary действие (справа)
- Деструктивные действия — `Popconfirm`, не отдельная модалка

---

## Уведомления (notification)

- `success` — после сохранения, переключения режима
- `error` — при ошибках, отказе доступа
- НЕ использовать `info` для системных событий (саммари, обновления) — это спам
- Все тексты через `t()`

## Что НЕ делать

- ❌ Ant Design `Card` для группировки полей — простые `<div>`
- ❌ `react-window` — несовместим с текущим стеком
- ❌ `danger` (красный) для не-деструктивных действий (возврат из режима)
- ❌ `Switch` для режимов с последствиями — только `<button>` с подтверждением
- ❌ `Input.TextArea` ref — использовать контролируемое состояние
- ❌ Синие ссылки в таблицах — вся строка кликабельна через `onRow`
- ❌ Эмодзи в интерфейсе
- ❌ Хардкод ширины для адаптивных элементов — только `max-width` или фиксированная для форм
- ❌ Inline-стили для заголовков страниц — только `<PageHeader>`
- ❌ Отдельный ряд для мобильной кнопки меню — кнопка внутри шапки на одной строке
- ❌ Дублирование навигационных пунктов в разных секциях сайдбара
- ❌ antd Tabs overflow-кнопка «...» на мобилке — нативный скролл
