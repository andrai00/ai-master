## 2. Новая логика игрового чата: общая кнопка ответа

**Сейчас:** каждое сообщение триггерит `runGameMasterBatch`.

**Новая логика:**
- Отправка сообщений **НЕ триггерит** AI
- Игроки пишут что хотят и сколько хотят — без ограничений
- У ВСЕХ одна общая кнопка: **«Запросить ответ ИИ мастера»**
- **Любой игрок** может нажать — не надо ждать всех
- Админ может заблокировать/отключить эту кнопку
- Пока AI думает — поле ввода блокируется у ВСЕХ
- AI отвечает одним сообщением, может обратиться к нескольким игрокам

### Реализация
- `send-game-message.ts` — убрать вызов `runGameMasterBatch`
- Общая кнопка в `ChatGameView`: «Запросить ответ ИИ мастера»
- Server action `requestMasterResponse(sessionId)` — запускает батч
- Админский toggle: заблокировать/разблокировать кнопку

## 3. Секретные действия через личный чат

### Обычные действия
- Игрок хочет сделать игровое действие в personal → AI говорит: «Это нужно сделать в общем чате»

### Секретные действия
- Игрок **явно хочет** чтобы никто не знал (разведка, скрытый бросок, личный план)
- Personal chat AI выполняет и пишет результат в `game_hidden` (тип: "secret_log")
- Формат: `"PlayerName: скрытно проверил восприятие → заметил засаду за дверью"`
- Game chat AI читает этот лог — понимает контекст когда игрок в общем чате намекает или действует
- Универсально: промптом, не кодом

### System prompt для personal chat
```
If a player wants to do a game action — tell them to use the game chat.
If a player explicitly wants to do something SECRET (hidden from other players):
1. Resolve it using the rules
2. Write outcome to game_hidden "Secret Actions Log" (type: secret_log)
3. Format: "[CharacterName]: action → result (mechanical details)"
4. The game chat GM reads this log. Do NOT copy to player's visible sheet.
```

## 4. Броски и формулы — для AI, не для игроков

### Что это
- AI читает character sheet, видит статы и бонусы
- AI сам строит формулу броска: `D20 + DEX_mod(4) + proficiency(2) = D20+6`
- **Не игроки бросают** — AI понимает механику и предлагает броски

### Частые броски
- AI может записать формулу броска отдельно (не только числовое значение)
- Например в character sheet: `**Скрытность:** D20 + ЛОВ + владение = D20+8`
- При обновлении стата — AI пересчитывает

### Формат формул
- AI сам решает как хранить (Markdown)
- Никакого зашитого формата — платформа не знает правил
- Движок формул (mathjs) — на будущее

- Убедиться что формулы работают и в Builder и в GM контексте

## 6. Сайдбар: документы игрока

- Каждый видит: свои `game_visible` (playerId = свой) + `game_visible` с `playerId = null` (общие)
- Админ тоже как игрок — видит только своё. Все документы: `/admin/documents`
- Секции: персонаж, инвентарь, шпаргалки, общая информация

---

## 7. Разделение знаний: правила vs сюжет

- **Правила (glossary/brain):** открыты всегда, игроки имеют право знать
- **Сюжет/секреты (game_hidden):** только когда персонаж обнаружил по ходу игры
- System prompt, без кода

---

## 8. Имена игроков и сопоставление с персонажами

- AI выделяет имена персонажей **жирным** в сообщениях
- AI знает кто есть кто: `userId` → character sheet → имя персонажа
- Обращается по имени персонажа, не по логину
- System prompt: таблица сопоставления в начало контекста

---

## 9. Режимы отправки (сводка)

| Чат | Как работает |
|-----|-------------|
| **Builder** | Отправил → AI думает (fire-and-forget, SSE) |
| **Personal** | Отправил → AI думает (блокировка ввода пока думает) |
| **Game** | Отправил → сообщение в чате. AI думает только по общей кнопке «Запросить ответ ИИ мастера». Любой может нажать. Блокировка у всех пока думает |
