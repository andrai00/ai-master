## 1. Протестировать создание персонажа

- [ ] Переключиться в game mode
- [ ] В personal chat написать "хочу создать персонажа"
- [ ] GM AI должен прочитать brain (порядок создания), glossary (расы, классы, статы)
- [ ] Пошагово провести: раса → класс → статы → навыки → имя
- [ ] На каждом шаге создавать/обновлять `game_visible` документ (character_sheet) через `update_char_sheet`
- [ ] Проверить что лист создался в БД (`category: "game_visible"`, `type: "character_sheet"`, `playerId` этого игрока)
- [ ] Проверить что игрок видит свой лист, но не видит чужие

**Что может пойти не так:**
- GM AI не понимает что создание персонажа — это personal chat, может попытаться в game chat
- `update_char_sheet` тулз не находит существующий документ чтобы обновить → создаёт дубликат
- Brain-документы не содержат порядок создания персонажа (Builder не сделал)

## 2. Кнопки бросков в чате

Сейчас GM AI может только сказать текстом "сделай бросок D20+5". Нужны кликабельные кнопки.

### 2a. Серверная часть — `present_roll_check` тулз
- Создать `gm-tools/gm-present-roll-check.tool.ts`
- Принимает: `{ checkName, diceExpression, targetPlayerId?, targetPlayers? }`
- Сохраняет в БД как специальное сообщение с `role: "master_roll_request"` (или новый тип)
- В UI: рендерится как кнопка с текстом "🎲 Скрытность D20+5"
- Игрок нажимает → вызывает `roll_dice` → результат идёт в чат

### 2b. Клиентская часть — рендер кнопки броска
- `ChatPanel` должен рендерить специальный тип сообщений с кнопкой
- При клике: вызывает `rollDiceAction` (новый server action или переиспользовать тулз)
- Показывает результат: бросок + модификатор = итог
- Результат отправляется как сообщение в тот же чат
- После броска кнопка исчезает (или становится disabled с текстом "Выпало: 18")

### 2c. Групповые броски
- `targetPlayers?: string[]` — бросить всем перечисленным игрокам
- `targetPlayers: "all"` — бросить всем игрокам в игре
- В UI рендерится как несколько кнопок или одна с подписью "(все игроки)"
- **Проблема:** после броска каждого игрока не должно тригериться новое AI-обдумывание
- **Решение:** результат броска сохраняется как `role: "roll_result"` сообщение, не триггерит `runGameMasterBatch`
- Все результаты видны в чате как обычные сообщения
- AI обрабатывает их только когда приходит новое текстовое сообщение

## 3. Броски с использованием листа персонажа

### 3a. Загрузка статов в контекст
- GM AI должен уметь читать character sheet игрока перед предложением броска
- Находить нужный стат (например "Скрытность +8") и подставлять в формулу броска
- Формат на усмотрение AI: "Сделай проверку скрытности D20+8"

### 3b. Авто-формулы
- Когда AI предлагает бросок, он ищет в character sheet соответствующий бонус
- Если character sheet хранит формулы (например `SKILL("stealth") + DICE("d20")`), AI должен их вычислить
- Движок формул (mathjs) — позже, сейчас просто ручной поиск бонуса

### 3c. Продумать формат данных листа
- Как AI хранит статы в character sheet?
  - Markdown таблица: `| STR | DEX | CON | ... |`
  - JSON в content: нет, только Markdown
  - Скрытые поля с формулами? Позже (composite-документы, этап 3 по роадмапу)
- AI сам решает структуру (см. принцип "нулевое знание о правилах в коде")

## 4. Сайдбар: список документов игрока

### 4a. FileTree с фильтрацией
- Сейчас `FileTree` в сайдбаре пустой — показывает документы игры
- Нужно показывать документы доступные текущему игроку:
  - `game_visible` с `playerId = текущий игрок` (личные листы)
  - `game_visible` с `playerId = null` (общие документы)
- Админ видит все + `brain` + `game_hidden`
- Группировка по `section` полю в Document

### 4b. Контекстные секции
- Из `01-concept.md` и `INTERFACE-STRUCTURE.md`:
  ```
  📁 Файлы игры
    ├── Мой персонаж → /characters/[id]
    ├── Инвентарь
    ├── Шпаргалки
    └── Общая информация
  ```
- Секции определяются `Document.section` и `Document.type`
- Builder настраивает какие секции видны
- Для MVP: просто плоский список с фильтром по категориям

### 4c. Иконка уведомления в сайдбаре
- "Непрочитанные" листы (новые/обновлённые GM'ом) — бейдж на пункте меню
- Сейчас не критично, отложить
