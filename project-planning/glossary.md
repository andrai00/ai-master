# Глоссарий проекта

## Термины

| Термин | Значение |
|---|---|
| **Builder** | Агент 1. Изучает правила, создаёт структуру мастера. Работает с админом |
| **Game Master** | Агент 2. Ведёт игру, используя структуру от Builder'а. Работает с игроками |
| **Админ** | Человек который настраивает мастера (создаёт/правит) |
| **Игрок** | Человек который играет (не трогает правила, не создаёт листы сам) |
| **Мастер** (конфигурация) | Вся структура созданная Builder'ом: правила, шаблоны, скилы, формулы |
| **Composite-документ** | Документ собранный из слоёв (раса + класс + уровень + ...) |
| **Слой** (composition layer) | Один кусок composite-документа (эльф, вор, 3 уровень) |
| **Три слоя данных** | Front-matter (скаляры) + companion-файл (сложное) + тело .md (видимое) |
| **Front-matter** | YAML в начале .md файла между `---`. Скрыт от игрока, содержит простые значения |
| **Companion-файл** | `data.yaml` рядом с `.md`. Скрыт, содержит сложные структуры (инвентарь, эффекты) |
| **Скрытые маркеры** | `<!-- meta:... -->` в теле .md. Не видны игроку, парсятся рендерером |
| **TL;DR** | Краткое описание в front-matter каждого файла правил (title + summary + keywords) |
| **_index.md** | Оглавление глоссария. Всегда в контексте агента. Карта всех правил |
| **Глоссарий** | Структурированные правила игры + словарь терминов |
| **Скил (skill)** | Загружаемая инструкция для агента под конкретный сценарий (.md файл) |
| **Инструмент (tool)** | Функция которую агент вызывает: read_file, search_content, send_chat... |
| **Progressive disclosure** | Стратегия послойного чтения: _index → TL;DR → полный файл → связи |
| **Семантический поиск** | Поиск по смыслу через эмбеддинги (в отличие от grep по ключевым словам) |
| **Миграция** | Процесс обновления существующих листов/данных при изменении правил мастером |
| **Сессия** | Одна игра/кампания: листы персонажей, состояние, логи |
| **Саммари** | Автоматическое сжатие истории чата для экономии контекстного окна |

## Каноническая структура папок

```
данные-мастера/
  masters/
    <master-id>/
      sources/              ← сырые файлы от админа (PDF, DOC, TXT)
      rules/                ← структурированные правила (Builder, НЕ менять)
        _index.md           ← оглавление глоссария
        .index/             ← эмбеддинги (embeddings.json + mapping.json)
        glossary.md         ← терминология
        races/              ← папки/файлы как решит нейронка
        classes/
        items/
        mechanics/
        ...
      skills/               ← игро-специфичные скилы (Builder)
      templates/            ← шаблоны листов (Builder, НЕ менять)
      config.yaml           ← настройки мастера
      formulas.yaml         ← формулы

  sessions/
    <session-id>/
      characters/
        <player-id>/
          _base.md          ← ядро листа
          _composition.yaml ← список слоёв
          data.yaml         ← companion: инвентарь, эффекты
      state/                ← состояние игры
        scene.md
        effects.yaml
        summary.md
      logs/                 ← история
        chat.md
        events.md
```
