## Этап 2: Builder — агент для админа

Админ общается в чате, загружает файлы, Builder:
- Парсит документы (PDF, DOC, TXT, MD)
- Структурирует правила
- Задаёт уточняющие вопросы (варианты A/B/C + свой ответ)
- Принимает правки текстом в чате

### Что делаем технически

1. Инструмент парсинга файлов — `pdf-parse`, `mammoth`
2. Инструменты файловой системы — read, write, list, search
3. Агентный цикл — AI SDK (`generateText` + `maxSteps`)
4. Интерактивные вопросы — агент умеет останавливаться и спрашивать
5. Чат-интерфейс (минимальный, консольный на старте)

### Что на выходе

Builder создаёт структуру мастера (см. `03-architecture.md` — каноническая структура папок). Формат внутри — зона нейронки, мы не диктуем.

## Этап 2: тестирование Builder'а

Без доработки кода пробуем:

- Загрузить правила небольшой игры
- Попросить создать персонажа
- Попросить посчитать по правилам
- Задать вопрос → получить ответ со ссылкой на источник
- Поправить мастера: "нет, эльфы +2 а не +1"
- Загрузить вторую игру — проверить что структура другая и ничего не сломалось

**Критерии:**
- Нейронка не выдумывает при парсинге
- Структура удобна для поиска
- Гибкость под разные игры подтверждена
- Размер контекстного окна не перегружается

Если на этом этапе проблемы — дальше нет смысла идти. Builder должен работать стабильно.

## Этап 3: рендерер и отображение

Когда Builder стабилен — делаем визуал:

- Рендерер Markdown со скрытыми маркерами
- Сборка composite-документов
- Отображение листов: три слоя данных (front-matter / companion / тело md)
- Интерфейс для игроков: дерево файлов, вкладки
- Drag-n-drop для слотов/инвентаря

---

## Этап 4: Game Master — второй агент

Подключаем агента который ведёт игру:

- Личные чаты + общий чат
- Инструменты поиска (полнотекстовый, семантический)
- Инструменты управления листами (update_char_sheet, add_composition_layer, ...)
- Кнопки бросков в чате
- Права доступа, скрытые действия
- Движок формул (реальное вычисление)

## Почему именно такой порядок

Builder — самый независимый кусок. Никакого UI кроме чата, никакого рендеринга, никакого второго агента. Если нейронка не справляется с парсингом и структурированием — дальше идти некуда.

Если Builder работает — у нас готовая структура данных под любую игру. Остальное — отображение и второй агент которые используют эту структуру. Итеративно, без прыжка через пропасть.
